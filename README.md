# المرجع القانوني العراقي — نسخة العرض

نسخة تجريبية تفاعلية من الموقع ولوحة التحكم، تعمل في المتصفح دون خادم.

- **الموقع:** الصفحة الرئيسية.
- **لوحة التحكم:** أضف `#admin` إلى آخر الرابط، أو اضغط «جرّب لوحة التحكم» في الشريط العلوي.
- النماذج لا تُرسل فعلاً، وتعديلات لوحة التحكم تُحفظ في متصفح كل زائر فقط. زر «مسح بيانات التجربة» يعيدها كما كانت.

النسخة الكاملة مع الخادم (PHP وMySQL) في حزمة `alqanony-public_html.zip`.
